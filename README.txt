САЙТ-ЗАПРОШЕННЯ ОКСАНИ ТА СЕРГІЯ

Файли:
- index.html: головна сторінка
- images/photo1.jpeg ... photo5.jpeg: ваші фотографії

ВАЖЛИВО:
1. Фото вже підключені до сторінки локальними файлами.
2. Музика ще не додана, бо аудіофайл не завантажено. Коли буде MP3, покладіть його поруч із index.html під назвою music.mp3.
3. RSVP у шаблоні поки демонстраційний. Щоб гості могли надсилати відповіді, підключіть Google Form.
4. Перед публікацією перевірте адресу карти й час подій.
5. Для GitHub Pages завантажте index.html і папку images у публічний репозиторій, потім Settings > Pages > Deploy from a branch > main > /(root).
